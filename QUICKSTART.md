# mangobutter Quick Start

Super is the mod key. Keys: `~/.config/mango/keybinds.conf`; startup programs: `autostart.conf`; your overrides: `local.conf`; the setup's defaults: `~/.local/share/mango/defaults.conf` (Super+Shift+r reloads live).

## Essentials
| Keys | Action |
|---|---|
| Super + Return | Terminal (kitty) |
| Super + ` | Drop-down terminal |
| Super + Space | App launcher (the bar's; rofi if the bar is down) |
| Super + / | Settings panel, Keybinds tab |
| Super + q | Close window |
| Super + Shift + q | Quit mango |
| Super + x | Power menu |

## Windows
| Keys | Action |
|---|---|
| Super + arrows / hjkl | Focus window |
| Super + Shift + arrows / hjkl | Swap window |
| Super + Ctrl + Left/Right | Master width |
| Super + Ctrl + Up/Down | Master count |
| Super + , / . | Focus previous / next monitor |
| Super + Shift + , / . | Send window to previous / next monitor |
| Super + Shift + Space | Toggle floating |
| Super + Shift + f | Fullscreen |
| Super + t | Cycle layouts |
| Super + w | Monocle |
| Super + Tab | Overview of all windows |
| Alt + Tab | Next window |

## Tags (workspaces)
| Keys | Action |
|---|---|
| Super + 1–9, 0, -, = | View tag 1–12 |
| Super + Shift + same | Send window to tag |
| Super + scroll wheel | Walk the tags |
| 3-finger swipe | Walk the tags (up: overview) |
| 4-finger swipe | Walk the tags, window comes along |

## Bar
| Keys | Action |
|---|---|
| Super + Shift + p | Settings panel, Wallpaper tab — a wallpaper re-themes bar, rofi, dunst, kitty, GTK and mango borders |
| Super + Shift + m | Command menu (power profile, keep awake, night light, DND, pomodoro) |
| Super + Shift + n | Network app (Wi-Fi, VPN, Bluetooth) |
| Super + Shift + t | Settings panel, Layout tab — layouts, gaps, blur / shadows / animations (also: right-click an empty stretch of the bar) |
| Super + s / Super + Shift + s | Screenshot full / region (saved to ~/Screenshots) |
